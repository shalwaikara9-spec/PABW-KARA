# PABW P10 — JavaScript Asinkron

Project ini merupakan website profil penghargaan yang mengambil data dari GitHub menggunakan Fetch API dan JSON.

## Fitur
- Menampilkan daftar lomba dan penghargaan.
- Filter kategori.
- Validasi form.
- Penanganan loading dan error.

## Teknologi
HTML, CSS, JavaScript, Fetch API, JSON, dan GitHub.

## Penggunaan AI
AI digunakan sebagai alat bantu untuk memahami kode, memperbaiki tampilan website, dan membantu menemukan kesalahan program.

## Cara Menjalankan
Buka `profil.html` menggunakan Live Server dengan koneksi internet aktif.
