## Tentang Proyek
Proyek ini adalah website Daftar Penghargaan Saya yang dibuat menggunakan Vue dan Vite. Website menampilkan profil, penghargaan, dan daftar proyek yang bisa difilter serta ditandai sebagai favorit.

## Versi Perangkat
- Node.js: v24.22.1
- npm: 11.19.1
- Vite: 8.3.5

## Cara Menjalankan
```bash
npm install
npm run dev
```

Untuk membuat dan mencoba hasil build:
```bash
npm run build
npm run preview
```

## Hasil Pengerjaan
Website berhasil dijalankan. Fitur filter dan favorit berfungsi, dan pilihan tetap tersimpan setelah halaman dimuat ulang. Hasil build juga berhasil dijalankan melalui preview.
