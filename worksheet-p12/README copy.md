## Pertemuan 11

### Deskripsi
Pada pertemuan ini, saya belajar memisahkan kode JavaScript menjadi beberapa file. Awalnya saya masih bingung dengan cara membagi kode, tetapi setelah dicoba, saya mulai memahami fungsi dari setiap file. Saya juga belajar supaya pilihan kategori dan favorit tidak hilang saat halaman dibuka ulang.

### Pembagian File
- `data.js`: untuk menyimpan data dan beberapa fungsi.
- `state.js`: untuk menyimpan data yang digunakan dalam aplikasi.
- `dom.js`: untuk mengatur tampilan halaman.
- `events.js`: untuk mengatur tombol yang bisa diklik.
- `app.js`: untuk menghubungkan semua file.
- `api.js`: untuk mengambil data proyek.

- Menyimpan pilihan kategori dan favorit.
- Menambahkan tombol Atur ulang.
